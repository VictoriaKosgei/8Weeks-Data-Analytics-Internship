# AnalystLab-Africa-Data-Analytics-Internship
# Week 1 — Online Retail Data Cleaning & Exploratory Data Analysis

## 📌 Project Overview

This project was completed as part of the **AnalystLab Africa Data Analytics Internship**.

The project focuses on cleaning, exploring, and analyzing an Online Retail transactions dataset using Python and Jupyter Notebook.

## 🎯 Objectives

* Inspect and understand the dataset
* Identify and handle missing values
* Investigate duplicate and invalid records
* Analyze sales and revenue performance
* Explore product and geographic performance
* Create meaningful data visualizations
* Develop business insights from the analysis

## 🧹 Data Cleaning

The dataset was examined and cleaned by:

* Checking the dataset structure and data types
* Investigating missing values
* Investigating duplicate records
* Handling invalid price values
* Investigating negative quantities and returns
* Creating a Revenue column
* Removing special transactions from product-sales analysis where appropriate
* Saving the cleaned dataset

## 📊 Exploratory Data Analysis

The analysis includes:

* Monthly revenue trends
* Top 10 products by revenue
* Top 10 products by quantity sold
* Top 10 countries by revenue
* Customer and geographic performance analysis

## 📈 Visualizations

Four visualizations were created using **Matplotlib** to identify important patterns in the data.

## 💡 Key Business Insights

* November 2011 recorded the highest monthly revenue in the available data.
* REGENCY CAKESTAND 3 TIER generated the highest product revenue.
* WORLD WAR 2 GLIDERS ASSTD DESIGNS had the highest quantity sold.
* The United Kingdom was the dominant market by revenue.
* Missing CustomerID values limit the completeness of customer-level analysis.
